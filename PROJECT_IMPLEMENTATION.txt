GOLIS 3D - PROJECT IMPLEMENTATION OVERVIEW
================================================================================

1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
GOLIS 3D is a high-performance, responsive single-page marketing website for
GOLIS — a technology partner that builds Websites, AI Agents & Business
Automation for small businesses, startups and growing companies.

Positioning:
"GOLIS builds high-performance websites, AI agents and business automation
that help businesses attract customers, automate repetitive work and operate
smarter."

Tech Stack:
- Core:            React 19, TypeScript, Vite
- 3D & Visuals:    Three.js, @react-three/fiber, @react-three/drei
- Animations:      Framer Motion, GSAP, CSS keyframes
- Styling:         CSS Modules, Modern CSS Custom Properties (Theme Variables)
- Deployment:      Docker (Nginx multi-stage), Render (render.yaml)
- Code Quality:    oxlint, TypeScript strict mode

3. 3D HERO EXPERIENCE (src/components/hero/)
================================================================================
HeroScene.tsx — Three.js & React Three Fiber:
  * Dynamic Brand Orb: Icosahedron mesh with MeshDistortMaterial, mouse-reactive
  * Orbital Rings: Multi-axis rotating torus meshes with glow shaders
  * Particles Field: Optimized buffer geometry floating points
  * Floating Cubes: Interactive wireframe meshes
  * Starfield Background: Dynamic depth star layer
  * Camera Rig: Parallax mouse tracking with lerped smoothing
  * Accessibility: prefers-reduced-motion detection, WebGL fallback, mobile fallback

Hero.tsx — Updated messaging:
  * Headline:     "Build Your Business with Websites + AI"

  * Primary CTA:  "Build My Solution" → #contact
  * Secondary CTA:"Explore AI Solutions" → #ai-solutions

5. AI SERVICES LAYER (src/services/ai/)  ← NEW
================================================================================
aiDemoService.ts
  * DemoType: 'chat' | 'sales' | 'lead' | 'business'
  * getDemoConfig(type) — returns welcome message + suggested questions
  * getDemoResponse(type, userMessage) — mock responses with realistic delay
  * createMessage(role, content) — creates ChatMessage with id + timestamp
  * Architecture note: replace getDemoResponse() body with a fetch() call to
    GOLIS backend API when real AI integration is ready
  * Security: NO API keys in this file or any frontend code
    Frontend → GOLIS Backend API → AI Provider / MCP / Database
